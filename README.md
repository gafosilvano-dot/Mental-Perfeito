#  Mental Perfeito — Projeto de Saúde Mental
> **Checkpoint 1** • Plataforma de suporte e acompanhamento de saúde mental para aqueles que desejam uma melhora e acompanhamento psicológico de qualidade.

---

##  1. Descrição do Problema
O projeto visa solucionar a solidão no combate aos problemas de saúde mental de pessoas que enfrentam uma rotina acelerada. Nosso objetivo é disponibilizar **acompanhamento psicológico online 24 horas** com profissionais especializados e dispostos a ouvir e aconselhar o paciente, prevenindo, minimizando e localizando o estresse e a ansiedade.

O foco abrange diferentes faixas etárias para alcançar o maior público possível, diminuindo os riscos de desenvolvimento de problemas neurológicos.

###  Bases de Dados Públicas e Reais Utilizadas:
* **DATASUS / Ministério da Saúde:** Dados epidemiológicos sobre transtornos mentais comuns (ansiedade e depressão) no Brasil.
* **IBGE (Pesquisa Nacional de Saúde - PNS):** Indicadores sobre estilo de vida, saúde mental e acesso a serviços de saúde da população jovem.
* **IHME (Institute of Health Metrics and Evaluation):** Estatísticas globais e dados consolidados sobre saúde pública.

---

##  2. Proposta de Solução Tecnológica
Idealizamos um ecossistema digital focado em acessibilidade e suporte preventivo em tempo real, contendo:
* **Atendimento 24h:** Profissionais especializados disponíveis a qualquer momento.
* **Autoavaliação:** Área dedicada para o usuário testar e entender seu estado atual.
* **Conteúdo Educativo:** Vídeos sobre bem-estar mental e atividades guiadas para momentos de picos de ansiedade.
* **Mapeamento Inteligente:** Direcionamento do usuário para pontos de apoio psicológico públicos.

###  Proposta de solução tecnológica


| **Linguagens** | Java, JavaScript, TypeScript | Linguagens base para construção do ecossistema. |
| **Frontend** | React + TypeScript | Interface do usuário moderna, tipada e componentizada. |
| **Backend** | Spring Boot (Java) | Criação da API e isolamento das regras de negócio. |
| **Banco de Dados**| DBeaver / SQL | Armazenamento flexível e seguro de perfis e registros diários de humor. |
| **Estilização** | Tailwind CSS | Design responsivo, moderno e de rápida implementação. |
| **Gráficos** | Chart.js | Geração de gráficos para evolução emocional do usuário. |

> **Nota de Arquitetura:** A separação entre o Frontend (React) e o Backend (Spring Boot) garante uma arquitetura limpa, facilitando a manutenção, segurança (anonimato dos registros de humor) e a evolução do sistema ao longo do semestre.
